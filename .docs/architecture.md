# Архитектура

Приложение разделено на клиент и API. Клиент рисует схему и сохраняет её. Сервер хранит название и содержание.

## Фронтенд

Код в `frontend/src`. Слой импортирует только слои ниже себя.

| Слой | Каталог | Роль |
| --- | --- | --- |
| app | `app` | Точка входа, маршруты, общие стили |
| pages | `pages/editor` | Страница редактора |
| widgets | `widgets` | Шапка, список схем, холст, палитра |
| features | `features` | Создание, поиск, удаление, постановка блока, связь, тема, выгрузка и вставка JSON |
| entities | `entities/scheme` | Схема: типы, каталог блоков, граф, хранилище Pinia, API, блок и стрелка |
| shared | `shared` | HTTP-клиент и компоненты shadcn-vue |

Маршруты:

- `/` — редактор без открытой схемы
- `/schemes/:id` — открытая схема

Состояние списка, открытой схемы и холста живёт в Pinia-хранилище `scheme`. Холст связан с ним через `v-model` узлов и рёбер Vue Flow. Изменение холста ставит сохранение в очередь на 450 мс. В базу уходит снимок графа без служебных полей выделения и размеров.

## Бэкенд

Приложение Django `schemes`, настройки в `config`.

Две таблицы:

- `Scheme` — название, даты создания и изменения
- `SchemeContent` — одна строка JSON на схему, связь один к одному, удаляется вместе со схемой

Содержание в базе — текст поля `payload`, не отдельный JSON-тип SQLite.

## API

Префикс `/api`.

| Метод | Путь | Действие |
| --- | --- | --- |
| GET | `/api/schemes/?search=` | Список схем, поиск по названию |
| POST | `/api/schemes/` | Создать схему с пустым графом |
| PATCH | `/api/schemes/:id/` | Переименовать |
| DELETE | `/api/schemes/:id/` | Удалить схему и содержание |
| GET | `/api/schemes/:id/content/` | Прочитать граф |
| PUT | `/api/schemes/:id/content/` | Записать граф, тело `{ "graph": { "nodes": [], "edges": [] } }` |

Поиск по кириллице считается в Python через `casefold`, потому что SQLite не приводит регистр Unicode в `LIKE`. Доступ к API открыт без авторизации.
