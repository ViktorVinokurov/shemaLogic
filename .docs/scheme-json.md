# Правила JSON логической схемы

Файл выгрузки — объект с названием и графом. В базе хранится только граф, строкой JSON в `SchemeContent.payload`.

```json
{
  "name": "Оплата заказа",
  "graph": {
    "nodes": [],
    "edges": []
  }
}
```

При вставке принимается и этот документ, и голый граф `{ "nodes": [], "edges": [] }`. Если названия нет, схема называется «Импортированная схема». Название обрезается до 255 символов. Пустая строка, не-JSON и объект без массивов `nodes` или `edges` отклоняются.

## Блок

```json
{
  "id": "start-1",
  "type": "logic",
  "position": { "x": 80, "y": 40 },
  "data": {
    "kind": "start",
    "label": "Старт"
  }
}
```

- `id` — непустая строка, уникальная внутри схемы.
- `type` — всегда `logic`.
- `position.x` и `position.y` — числа.
- `data.kind` — одно из `start`, `process`, `condition`, `io`, `end`.
- `data.label` — строка. Пустая подпись заменяется подписью по умолчанию этого вида.

Блок без `id`, координат или допустимого `kind` отбрасывается. Если в файле были блоки и ни один не прочитался, вставка завершается ошибкой.

## Ответвления условия

Только у `kind: "condition"`. Ровно два ответвления, идентификаторы фиксированы: `yes` и `no`.

```json
"branches": [
  { "id": "yes", "side": "bottom", "outcome": "yes" },
  { "id": "no", "side": "right", "outcome": "no" }
]
```

- `side` — `top`, `right`, `bottom` или `left`.
- `outcome` — `yes` (на схеме «Да») или `no` (на схеме «Нет»).

Если `branches` нет или запись испорчена, подставляются значения по умолчанию: «Да» снизу, «Нет» справа. Оба ответвления могут иметь один и тот же результат и одну сторону; на одной стороне точки разводятся.

## Связь

```json
{
  "id": "edge-1",
  "source": "start-1",
  "target": "step-1",
  "sourceHandle": "out",
  "targetHandle": "in",
  "type": "labeled"
}
```

- `id`, `source` и `target` — строки. `source` и `target` должны указывать на существующие блоки.
- `sourceHandle` у обычного блока — `out`. У условия — `yes` или `no`.
- `targetHandle` — `in`.
- `type` — `labeled`.
- Для ветки условия добавляются `outcome` (`yes` или `no`) и `label` (`Да` или `Нет`).

Связь в никуда отбрасывается. Нельзя связать блок с самим собой, начать стрелку из «Конца» и привести стрелку во «Старт». Повтор той же пары `source`, `target` и `sourceHandle` не создаётся.

Пример ветки «Да»:

```json
{
  "id": "edge-yes",
  "source": "check-1",
  "target": "end-1",
  "sourceHandle": "yes",
  "targetHandle": "in",
  "outcome": "yes",
  "label": "Да",
  "type": "labeled"
}
```

Тело `PUT /api/schemes/:id/content/` — `{ "graph": { "nodes": [], "edges": [] } }`. Поля `name` в это тело не входит: название меняется отдельно, через схему.
